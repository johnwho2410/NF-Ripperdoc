NF-RIPPERDOC (GameDoctor) 0.1.0 – Cyberpunk 2077 Mod-Diagnose
=============================================================

DEUTSCH
-------
Was ist das?
  Ein Werkzeug, das Abstürze und Performance-Probleme von Cyberpunk 2077 analysiert:
  Absturzursachen, verdächtige Mods, Mod-Umgebung, FPS/Frametimes und konkrete Empfehlungen.

Starten
  1. GameDoctor.exe doppelklicken. Es ist keine Installation und kein .NET nötig.
  2. Windows SmartScreen kann warnen, weil das Programm nicht signiert ist:
     „Weitere Informationen“ -> „Trotzdem ausführen“.
  3. Die Sprache folgt Windows (Deutsch, sonst Englisch). Mit dem Knopf oben („English“ / „Deutsch“) wechselbar.

Wichtig
  - GameDoctor verändert NIEMALS deine Mods. Änderungen machst du selbst, z. B. in Vortex oder Mod Organizer 2.
  - Für die Frame-Analyse lädt GameDoctor auf Nachfrage PresentMon (Intel, Open Source) herunter – nur nach deiner Zustimmung.
  - Das Ingame-Overlay braucht den Fenstermodus „Randloses Fenster“. Ein/Aus: Strg+Umschalt+O.
  - Die KI-Auswertung nutzt deinen eigenen Zugang oder ein lokales Modell. Daten werden nur auf Klick gesendet.
  - Einstellungen und Aufnahmen liegen unter %LOCALAPPDATA%\GameDoctor.

ENGLISH
-------
What is this?
  A tool that analyzes Cyberpunk 2077 crashes and performance problems:
  crash causes, suspect mods, mod environment, FPS/frame times and concrete recommendations.

Getting started
  1. Double-click GameDoctor.exe. No installation and no .NET required.
  2. Windows SmartScreen may warn because the program is not signed:
     "More info" -> "Run anyway".
  3. The language follows Windows (German, otherwise English). Switch with the button at the top ("English" / "Deutsch").

Important
  - GameDoctor NEVER changes your mods. You make changes yourself, e.g. in Vortex or Mod Organizer 2.
  - For frame analysis, GameDoctor offers to download PresentMon (Intel, open source) – only with your consent.
  - The in-game overlay needs "Borderless windowed" mode. Toggle: Ctrl+Shift+O.
  - AI analysis uses your own account or a local model. Data is only sent when you click.
  - Settings and recordings are stored in %LOCALAPPDATA%\GameDoctor.
